# My Reflection

This laboratory helped me understand how Docker Compose makes deploying applications easier. Instead of typing commands for each container one by one, I could put their settings in a single `docker-compose.yml` file. This made the process more organized and saved time because I could start the services together with just one command.

I also learned that even a small mistake in YAML indentation can cause problems. For example, using a Tab instead of spaces or placing a line in the wrong position can make the configuration invalid. Because of this, I realized that I need to be careful when writing YAML files and always check the indentation before running the commands.

Another thing I learned was how environment variables work. Values like `MYSQL_PASSWORD` and `MYSQL_DATABASE` provide the information needed to configure the database and connect it to Nextcloud. I now understand why these settings are important for making sure the two services can communicate properly.

For me, it was exciting to see how Nextcloud and MariaDB could work together to create a private cloud storage system in just a few minutes. Although the configuration looked confusing at first, understanding what each service does made it easier to follow. It also felt rewarding to see how the commands and configuration file could be used to build something practical.

Since Mission 1, my understanding of Cloud Computing has improved little by little. Before, I mostly thought of it as storing files and accessing services online. Now, I understand that it also involves managing infrastructure, running containers, connecting applications, and automating tasks. I know I still have a lot to learn, but this activity helped me become more familiar with cloud technologies and gave me more confidence in trying them on my own.
