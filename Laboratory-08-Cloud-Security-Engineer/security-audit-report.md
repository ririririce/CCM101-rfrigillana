# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving each user only the access and permissions they need to do their tasks. This is important in cloud computing because it helps protect files and systems from unauthorized access and prevents users from making changes they are not supposed to make.

## 2. Attack Surface

The attack surface refers to all the possible ways an attacker could try to access or harm a virtual machine. These include open ports, running applications, and services that may have security weaknesses. Keeping only the necessary ports and services active helps reduce the chances of an attack.

## 3. Default Deny Policy

A Default Deny Policy means blocking all incoming traffic unless it is specifically allowed by the firewall. This is safer because attackers can use different methods to access a server, and blocking only known threats may not stop new ones. By allowing only trusted and necessary connections, we can better protect the server from unauthorized access.
