# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is one of the most widely used cloud computing platforms in the world. It provides different services that allow individuals and organizations to use computing resources through the internet instead of maintaining all of the physical hardware themselves.

AWS offers services for computing, storage, databases, networking, security, artificial intelligence, and many other areas. Because of its wide range of services, it can support both small startups and large enterprises.

## Global Infrastructure

AWS has a large global infrastructure that is divided into geographic **Regions** and **Availability Zones**. A Region represents a specific geographic area, while Availability Zones are separate locations within a Region.

Having multiple locations allows organizations to place their applications closer to their users and improve availability. Companies can also choose a Region based on factors such as location, performance, data requirements, and the services available in that area.

## Cloud Management Console

The **AWS Management Console** is a web-based interface where users can access and manage AWS services. Instead of using only command-line tools, users can use the console to create and configure resources through a graphical interface.

For example, users can create virtual machines, manage storage, configure networks, monitor resources, and manage security settings from the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and other workloads. Users can choose different instance types depending on how much computing power their application needs.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is used for storing files and other types of data. It can be useful for backups, application files, images, videos, and large amounts of data.

### 3. Amazon RDS

Amazon Relational Database Service (RDS) is a managed database service. It makes it easier for organizations to set up, operate, and maintain relational databases without handling every database administration task themselves.

### 4. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create a private network within AWS. It can be used to organize resources, control network traffic, and create secure connections between different cloud resources.

## Three Advantages

1. **Scalability** – AWS resources can be increased or decreased depending on the needs of an application.

2. **Global Infrastructure** – AWS has cloud infrastructure in many locations around the world, allowing businesses to serve users from different regions.

3. **Wide Range of Services** – AWS provides many different services for computing, storage, databases, networking, security, AI, and other technologies.

## Typical Enterprise Use Cases

AWS can be used by businesses for many different purposes, such as:

- Hosting websites and web applications
- Storing and backing up business data
- Running databases
- Hosting enterprise applications
- Disaster recovery
- Development and testing
- E-commerce applications
- Artificial Intelligence and Machine Learning
- Global application deployment
- High-performance computing
