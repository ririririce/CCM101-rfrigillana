# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides different services that organizations can use to build, run, store, and manage applications and data through the cloud.

Azure offers services for computing, storage, databases, networking, security, artificial intelligence, and application development. One of its major strengths is its connection with other Microsoft technologies, which makes it a useful option for organizations that already use Microsoft products.

## Global Infrastructure

Azure has a global cloud infrastructure made up of regions and data centers located in different parts of the world. These locations allow organizations to deploy their applications closer to their customers and users.

Azure also organizes its infrastructure into geographic areas to help organizations meet requirements related to performance, availability, data residency, and compliance.

Choosing an appropriate Azure region is important because not every service is available in every location. Organizations need to consider their users, data requirements, and the services they plan to use.

## Cloud Management Console

The **Azure Portal** is Microsoft's web-based management interface for Azure. It allows users to create, manage, and monitor their cloud resources using a graphical interface.

Through the Azure Portal, users can manage virtual machines, storage, databases, networks, applications, subscriptions, and other Azure services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines allows users to create virtual computers in the cloud. These machines can run Windows or Linux and can be used for applications, websites, databases, and other workloads.

### 2. Azure Blob Storage

Azure Blob Storage is a service used to store large amounts of unstructured data. It can be used for files, backups, images, videos, archives, and data used by applications.

### 3. Azure SQL Database

Azure SQL Database is a managed relational database service based on Microsoft's SQL Server technology. Azure handles many of the maintenance tasks, allowing organizations to focus more on their applications and data.

### 4. Azure Virtual Network

Azure Virtual Network allows users to create private networks for their cloud resources. It can help organizations control communication between resources and connect their Azure environment with existing on-premises networks.

## Three Advantages

1. **Microsoft Integration** – Azure works well with Microsoft technologies such as Windows Server, Microsoft 365, SQL Server, and Microsoft identity services.

2. **Hybrid Cloud Support** – Azure can connect cloud resources with existing on-premises systems, which is useful for organizations that are not ready to move everything to the cloud.

3. **Global Availability** – Azure has infrastructure in many locations around the world, allowing organizations to deploy services closer to their users.

## Typical Enterprise Use Cases

Azure can be used by organizations for:

- Hosting Windows and Linux applications
- Migrating existing enterprise systems
- Hybrid cloud environments
- Database hosting
- Web application hosting
- Microsoft technology integration
- Backup and disaster recovery
- Artificial Intelligence and Machine Learning
- Virtual desktops
- Data analytics
- Global application deployment
