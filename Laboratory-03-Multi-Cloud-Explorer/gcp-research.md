# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is Google's cloud computing platform. It provides services that organizations can use for computing, storage, databases, networking, data analytics, artificial intelligence, machine learning, and application development.

Google Cloud is commonly associated with data, AI, machine learning, and container technologies. It can be used by both smaller development teams and large organizations that need scalable cloud infrastructure.

## Global Infrastructure

Google Cloud uses a global infrastructure made up of **Regions** and **Zones**. A Region represents a geographic location, while Zones are separate locations within a Region.

Using multiple zones can help organizations improve the availability of their applications. Businesses can also choose locations based on factors such as user location, performance, data requirements, and service availability.

Google Cloud also uses Google's global network to connect its cloud infrastructure and provide connectivity between different locations.

## Cloud Management Console

The **Google Cloud Console** is a browser-based interface for managing Google Cloud resources. It allows users to create and monitor resources without having to rely completely on command-line tools.

Through the console, users can manage projects, virtual machines, storage, networks, databases, Kubernetes clusters, billing, and other Google Cloud services.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that run on Google's infrastructure. These virtual machines can be used to host websites, applications, databases, and other workloads.

### 2. Cloud Storage

Cloud Storage is Google's object storage service. It allows users to store files and other types of data in cloud storage buckets and can be used for backups, application data, archives, and analytics.

### 3. Cloud SQL

Cloud SQL is a managed relational database service. It makes it easier for organizations to use relational databases without having to manage all of the underlying infrastructure themselves.

### 4. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking for resources running in Google Cloud. It allows organizations to control how their cloud resources communicate and can be used with services such as virtual machines and Kubernetes.

## Three Advantages

1. **Strong AI and Data Capabilities** – Google Cloud provides many services for artificial intelligence, machine learning, data analytics, and big data processing.

2. **Global Network** – Google's global network connects its cloud infrastructure across different locations, which can help applications communicate efficiently.

3. **Managed Services** – Many Google Cloud services are managed by Google, reducing the amount of infrastructure maintenance that organizations need to perform themselves.

## Typical Enterprise Use Cases

Google Cloud can be used by organizations for:

- Artificial Intelligence and Machine Learning
- Data analytics
- Big data processing
- Kubernetes and containerized applications
- Website and application hosting
- Database hosting
- Application modernization
- Backup and disaster recovery
- Global application deployment
- High-performance computing
