# Cloud Platform Recommendations


---

## Client A – Startup Company

### Recommended Platform: AWS

I would recommend **AWS** for this startup because it has many services that can help them launch their mobile application without needing to set up their own physical servers. Since their budget is limited, they can start with smaller resources and increase them as the number of users grows. AWS also has different services for running the application, storing data, and managing the database. This gives the startup room to grow without having to completely change its setup later.

**Services the client could use:**
- **Amazon EC2** – for running the application's servers.
- **Amazon S3** – for storing images, files, and other application data.
- **Amazon RDS** – for managing the application's relational database.

---

## Client B – University

### Recommended Platform: Microsoft Azure

I would recommend **Microsoft Azure** because the university already uses Windows Server, Microsoft 365, and Active Directory. Since these technologies are already part of Microsoft's ecosystem, Azure would make it easier to connect the university's existing systems with cloud services. The university could move some of its services to Azure while still working with its existing Microsoft environment. This can make the transition to the cloud easier and more familiar for the university's IT staff.

**Services the client could use:**
- **Azure Virtual Machines** – for running Windows Server and other applications.
- **Microsoft Entra ID** – for managing user identities and access.
- **Azure Blob Storage** – for storing documents, backups, and other files.
- **Azure Virtual Network** – for connecting and securing cloud resources.

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud

I would recommend **Google Cloud** because the company mainly works with Artificial Intelligence and Machine Learning and needs high-performance computing. Google Cloud has services that are specifically useful for building, training, and deploying AI and Machine Learning applications. It also provides computing resources that can be used for demanding research projects. Because of these features, Google Cloud would be a good fit for the company's AI-related work.

**Services the client could use:**
- **Vertex AI** – for developing, training, and deploying Machine Learning models.
- **Compute Engine** – for running virtual machines and high-performance workloads.
- **Cloud Storage** – for storing large datasets and other research files.
- **Google Kubernetes Engine (GKE)** – for running and managing containerized applications.

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

I would recommend **AWS** for this company because it needs reliable infrastructure that can handle customers from different parts of the world. AWS provides services that can help keep the online store available while also allowing its resources to increase when there is a sudden increase in traffic. This would be especially useful during holidays, promotions, or major sales when many customers may visit the website at the same time. AWS also provides services for distributing traffic and delivering content to users around the world.

**Services the client could use:**
- **Amazon EC2** – for running the e-commerce application's servers.
- **Elastic Load Balancing** – for distributing incoming traffic across servers.
- **Amazon EC2 Auto Scaling** – for automatically increasing or decreasing computing resources based on demand.
- **Amazon S3** – for storing product images, files, and other data.
- **Amazon CloudFront** – for delivering website content to customers around the world.

---

## Summary

| Client | Recommended Platform | Main Reason |
|---|---|---|
| **Client A – Startup Company** | AWS | Flexible services and the ability to grow as the application gains users |
| **Client B – University** | Microsoft Azure | Works well with the university's existing Microsoft technologies |
| **Client C – AI Research Company** | Google Cloud | Strong support for AI, Machine Learning, and high-performance computing |
| **Client D – Global E-Commerce Company** | AWS | Supports high availability, scaling, and global users |

## Conclusion

The best cloud platform depends on what each client needs. I chose AWS for the startup because it gives the company room to grow, Azure for the university because it already uses Microsoft technologies, and Google Cloud for the AI research company because of its AI and Machine Learning capabilities. For the global e-commerce company, AWS is a good choice because it can support a large number of users and handle changes in website traffic.
