# Cloud Provider Comparison

[svg](https://github.com/riririce/CCM101-rfrigillana/blob/main/Laboratory-02-Build-the-Cloud-Infrastructure-Blueprint/cloud-provider-comparison.md#cloud-provider-comparison)

This comparison looks at how the three major public cloud providers provide similar infrastructure services. Although the services have different names, they generally serve similar purposes when building and managing cloud environments.

The information in this comparison is based on the official documentation of Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

---

## Infrastructure Service Comparison

[svg](https://github.com/riririce/CCM101-rfrigillana/blob/main/Laboratory-02-Build-the-Cloud-Infrastructure-Blueprint/cloud-provider-comparison.md#infrastructure-service-comparison)

| **Infrastructure Component** | **Amazon Web Services (AWS)** | **Microsoft Azure** | **Google Cloud Platform (GCP)** |
|---|---|---|---|
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking** | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS IAM | Azure RBAC | Google Cloud IAM |

## Guide Questions

[svg](https://github.com/riririce/CCM101-rfrigillana/blob/main/Laboratory-02-Build-the-Cloud-Infrastructure-Blueprint/cloud-provider-comparison.md#guide-questions)

### 1. Which cloud provider offers the broadest range of services?

[svg](https://github.com/riririce/CCM101-rfrigillana/blob/main/Laboratory-02-Build-the-Cloud-Infrastructure-Blueprint/cloud-provider-comparison.md#1-which-cloud-provider-offers-the-broadest-range-of-services)

AWS offers a broad range of cloud services covering areas such as computing, storage, networking, databases, security, and analytics. Its large selection of services makes it suitable for organizations with different types of cloud requirements.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

[svg](https://github.com/riririce/CCM101-rfrigillana/blob/main/Laboratory-02-Build-the-Cloud-Infrastructure-Blueprint/cloud-provider-comparison.md#2-which-cloud-platform-would-you-recommend-for-an-organization-that-primarily-uses-microsoft-products-why)

I would recommend Microsoft Azure for an organization that primarily uses Microsoft products. Azure works closely with Microsoft's ecosystem, making it a practical choice for organizations already using Microsoft technologies and services.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

[svg](https://github.com/riririce/CCM101-rfrigillana/blob/main/Laboratory-02-Build-the-Cloud-Infrastructure-Blueprint/cloud-provider-comparison.md#3-which-platform-is-widely-recognized-for-artificial-intelligence-ai-machine-learning-ml-and-kubernetes-services)

Google Cloud is widely recognized for its capabilities in Artificial Intelligence, Machine Learning, and Kubernetes. Google also created Kubernetes, making Google Cloud a strong option for organizations working with containers and cloud-native applications.

### 4. What similarities did you observe among the three cloud providers?

[svg](https://github.com/riririce/CCM101-rfrigillana/blob/main/Laboratory-02-Build-the-Cloud-Infrastructure-Blueprint/cloud-provider-comparison.md#4-what-similarities-did-you-observe-among-the-three-cloud-providers)

All three providers offer services for the basic parts of cloud infrastructure, including compute, storage, networking, and identity and access management. The names and specific features differ, but the main purpose of these services is similar across the three platforms.

## Conclusion

[svg](https://github.com/riririce/CCM101-rfrigillana/blob/main/Laboratory-02-Build-the-Cloud-Infrastructure-Blueprint/cloud-provider-comparison.md#conclusion)

AWS, Microsoft Azure, and Google Cloud provide the core infrastructure needed to build cloud-based systems. While each provider uses different service names and features, the basic concepts remain similar: compute resources run workloads, storage keeps data, networking connects resources, and identity and access management controls access to those resources.
