# Mission Reflection
This lab activity really helped me get a hands-on feel for cloud computing. Instead of just sitting through lectures and taking notes, I actually got to work inside a real Linux environment—and that made all the difference.

What stood out to me the most was just how crucial networking is in the cloud. Every component has its part to play, sure, but without a solid network, nothing really works. It's the bridge that connects users, apps, and storage. If that connection isn't there, even the most powerful compute resources are practically useless because nobody can access them.

I also got a better sense of why Linux is such a big deal in the cloud. Using KillerCoda, I ran various commands to check things like the OS, kernel, CPU, memory, storage, hostname, and IP address. It gave me a much clearer picture of how systems are monitored and managed in a cloud setup. On top of that, I realized just how valuable technical documentation is before you even start deploying anything. It keeps everything organized and makes life so much easier when you're troubleshooting, maintaining, or scaling things up later.

Throughout this mission, I picked up a bunch of practical skills too. I'm way more confident navigating the Linux terminal now, creating and editing Markdown files with Nano, and exploring directory structures using Tree. My Git and GitHub workflow also got a nice boost—I'm more comfortable cloning repos, staging files, committing changes, and pushing updates. Researching AWS, Azure, and Google Cloud also opened my eyes to how different providers offer similar services in their own way.

Looking back, I think my GitHub portfolio is in a much better place now. It includes a complete cloud lab activity with documentation, research, and even a diagram for Digimart's cloud infrastructure. But more than that, this experience gave me practical know-how that I know I'll keep using as I move forward in my BSIT journey.
