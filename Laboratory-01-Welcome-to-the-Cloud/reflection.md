## Looking Back

Laboratory 01 served as my introduction to the world of Linux, cloud computing, and version control. At first, I found working entirely through the terminal unfamiliar because I was more accustomed to graphical interfaces. However, as I completed each checkpoint, I became more comfortable using Linux commands and navigating the command-line environment.

One of the most valuable parts of this activity was creating my own GitHub portfolio. It helped me understand how developers and cloud engineers organize projects, track changes, and document their work professionally. Learning Markdown also allowed me to create clean and readable documentation that can easily be shared with others.

Throughout the activity, I encountered several challenges. I experienced issues with Git not updating my repository, confusion about why empty folders were not appearing on GitHub, and permission problems when using `sudo`. Although these obstacles were frustrating at first, troubleshooting them taught me the importance of reading terminal messages carefully, understanding how Git works, and finding the correct solutions instead of guessing.

Overall, this laboratory strengthened my confidence in using Linux commands, managing files and directories, gathering system information, and using Git and GitHub for version control. These are fundamental skills that I know will be useful in future laboratory activities and eventually in real-world cloud computing and system administration.

This activity reminded me that learning cloud computing is not just about memorizing commands—it's about understanding how different tools work together to solve real problems. I look forward to applying these skills in the succeeding laboratories and continuously improving my technical knowledge.
